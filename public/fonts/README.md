# Fontes da interface

Manrope nos títulos, identidade e navegação; Source Sans 3 nos enunciados, alternativas, mensagens e formulários. Arquivos variáveis WOFF2 com subconjuntos latino e latino estendido, incluindo os acentos do português. O carregamento usa `font-display: swap`, com fontes do sistema como alternativa.

Distribuição oficial: Google Fonts. Licenças SIL Open Font License incluídas em `manrope-LICENSE.txt` e `sourcesans3-LICENSE.txt`. Os arquivos são servidos pelo próprio aplicativo, sem requisições externas de fonte durante o uso.
